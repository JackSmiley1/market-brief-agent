Methodology

Every nightly pick gets a self-rated confidence level and an event-risk flag from Claude's own read of the setup. Position size is cut for low confidence, scheduled-event risk, and short positions — not by assumption, but because each one was shown to correlate with worse real outcomes in this system's own trade history.
